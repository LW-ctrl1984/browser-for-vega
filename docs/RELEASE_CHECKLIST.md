# Release Checklist

Before publishing a release:

- [ ] Build from the intended source revision.
- [ ] Confirm the displayed app name is **Browser for Vega**.
- [ ] Confirm the About page contains the independent-project notice.
- [ ] Confirm the GitHub link points to this repository.
- [ ] Confirm the version number matches the release tag.
- [ ] Verify the application icon and promotional assets contain no unauthorized third-party logos or copyrighted entertainment imagery.
- [ ] Verify third-party dependency licenses and notices.
- [ ] Test core browsing and remote-control navigation.
- [ ] Test localization fallback behavior.
- [ ] Test Arabic RTL layout.
- [ ] Scan the repository and package for credentials, secrets, private keys, tokens, and personal data.
- [ ] Verify the `.vpkg` package name and checksum before attaching it to GitHub Releases.
- [ ] Re-check current Vega OS developer requirements because platform requirements can change.
- [ ] If submitting to an app store, separately re-check that store's current metadata and branding requirements.
